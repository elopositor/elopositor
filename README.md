### Cómo me gusta hacer las cosas

- **Que funcione sin mí.** Un cron, una tarea programada o un workflow antes que un proceso
  que alguien tiene que acordarse de lanzar.
- **La opción barata primero.** Casi todo esto corre con 0 € al mes. Cuando algo cuesta
  dinero, lo digo antes de montarlo.
- **Documentar la decisión, no solo el código.** En mis README está por qué se descartó la
  otra opción, que es lo que de verdad se olvida.
